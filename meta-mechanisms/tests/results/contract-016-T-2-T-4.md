# contract-016 T-2, T-3 and T-4 — the upgrade procedure split into steps, and nothing lost

**Date:** 2026-09-19. The pioneer's line for this contract: *"Disappointment is if we break the bootstrap in any way."*

## How the split was made

Not by hand. A script was given, for each of the ten long paragraphs, a list of places — each a few words of the
paragraph's own text — and could do one thing only: replace the single space in front of such a place with a line
break, either a new paragraph inside the same step or a bullet. A place that did not occur exactly once in its
paragraph stopped the script before anything was written. No word was typed into the skill.

| Paragraph | Before | Longest line after |
|---|---|---|
| *What "the kit" is* | 1,933 bytes | under 390 bytes |
| *The template rule* | 1,916 | 408 |
| step 1, stage it | 1,201 | 499 |
| step 2, rehearse on a copy | 4,078 | 435 |
| step 3, lay of the land (lead) | 1,369 | 412 |
| step 3, *evolved here* | 3,834 | 669 |
| step 5, install | 1,766 | 604 |
| step 7, the manifest line | 2,380 | under 390 |
| step 8, map the project's nodes | 1,362 | 768 |
| step 9, the ratification pass and the close | 2,530 | 450 |

The longest line anywhere in the skill is now 1,147 bytes (the stale-files rule of step 3, which was under the
allowance already and was not touched).

## T-2 — the words are the same

`tests/same-words.sh <before> <after>` brings every run of whitespace to one space, drops a list marker that opens a
line, and compares what is left character for character.

- The skill before the contract against the skill after: **identical, 64,977 characters.**
- The install half — everything above *Upgrading an Existing Install* — is byte for byte unchanged (same hash, the
  heading on the same line, 383).
- The proof can fail: with one word added to the new text ("Discard the copy at once."), the script stopped at
  character 45,099 and showed both versions of the sentence.

## T-3 — the walk's searches of the skill's wording

Twenty-one lines of `walk-007.sh` search `meta-bootstrap/SKILL.md` for wording, some for several phrases. The
contract's diff of that file removes two lines, both version searches (0.23 to 0.24); no state that searches the
bootstrap's wording was edited, and all of them pass. None of the searched phrases crossed a place where a line
break was put.

## T-4 — two readers, one given the old text and one the new

Each was an independent agent given one file — the upgrade section as it was, or as it is — and asked to list, in
order, everything the text tells the agent to do and everything it forbids, for the rehearsal step and the *evolved
here* rule, each line ending in the text's own words. Neither knew another version existed.

| | Reader of the old text | Reader of the new text |
|---|---|---|
| rehearsal step, must do | 44 lines | 49 lines |
| rehearsal step, must never | 10 | 11 |
| *evolved here*, must do | 35 | 33 |
| *evolved here*, must never | 12 | 10 |

**The order of instructions is the same in both lists, and nothing the upgrading agent has to do or avoid appears
in one and is missing from the other.** Three lines appear in the old text's list only; each is set out below. The
counts differ for three reasons, all of them the readers' cutting rather than the text:

- The eight standing questions. The old text gave them inside one sentence and its reader wrote one line for all
  eight; the new text gives them as eight bullets and its reader wrote eight lines. This is the split doing what it
  was for.
- Small merges going each way: the old text's reader gave the definition of a re-wrapped line two lines, the new
  one's gave it one; the new one's added "do not run steps 3 to 9 before the copy is discarded" as a prohibition,
  which the old one's had as the last instruction. The old text's reader also gave a line to *"regenerated by
  `history/regenerate.sh` before a release"*; the new one's did not. It says how the kit is released, not what the
  upgrading agent does.
- Two sentences of reasoning. *"meta skills are the kit's and are not meant to be changed by a project"* and *"a
  decision per file, never a silent loss"* were listed as prohibitions by the old text's reader and not by the new
  one's. The instruction they lead to — one sheet line per differing file — is in both readers' lists. The sentence is
  word for word the same in both texts and now stands as its own paragraph. **Recorded, not changed:** it states why
  the question exists, the instruction it supports is in both lists, and no word of it could be altered under this
  contract.

## What this does not show

That an agent carries out an upgrade better from the new text. Two readers listing instructions is a reading test.
The rehearsal on the shipped fixtures, which comes next, is where the procedure is followed rather than read.
