# contract-022 — one question at a time (T-1 to T-7)

**Date:** 2026-09-21. The loop was drawn with every stop marked, and three of them turned out to be carrying
more than one kind of question. This contract separates them, and gives the pioneer a way to see what is
queued on their decision without asking for it.

## T-1 (G-1) — the bearing is served alone

`walk-007` state 202. The contract skill now says the drawn contract opens with the bearing and one line
saying everything below is derived from it, so stopping there costs nothing; and it says in the same breath
that this is presentation, not a second stop — the gate remains one stop, which contract-011 fought for.

**The half this state cannot prove.** Whether a drawn contract actually *reads* that way is behaviour, not
text. The state holds the rule; T-7 holds the behaviour, and it is deferred below. Said plainly rather than
counted as passed.

## T-2 (G-2) — three asks at the gate, and the choices move

State 203. The gate section now carries *"Those three asks, and nothing else"* and sends a load-bearing choice
to the spec lock **before the tiers exist**, where it is answered while nothing has been derived from it. A
choice that is not load-bearing is the agent's, named in Tier 2 as decided-and-why so the pioneer can overturn
it. And if a load-bearing choice surfaces after the tiers are drawn, the text says the lock was skipped — go
back to it rather than smuggling the question into the gate.

The spec lock no longer names a specific tool. It said to use one particular question tool; an agent without
it degraded the step in silence, which a cold-start agent found and reported two days ago. It now says to put
the choices in whatever way the session allows, each with what it costs.

## T-3 (G-3) — what waits on the pioneer, unasked

State 204, run over this repository's own records. The list reports what is queued on the pioneer's decision,
oldest first, one line each. On this repository it finds one thing — a contract whose checks came back with
something unresolved — and says so in words the pioneer does not have to translate.

The session-start hook hands the agent the task of putting it to them at the start of a sitting. **It is never
something the pioneer asks for**, which P-004 requires: no step of the lifecycle may depend on a command the
human runs. The script produces the material; the agent puts it in words, because a script cannot translate.

## T-4 (G-3) — a batch is one line, with no count

State 205. On a fixture where four items would go into a review batch, the list says only that *a review of
what would change the standard is waiting for you* — one line, no number, no kinds. The state fails if a digit
appears in that line at all.

This is contract-011's rule kept: the count of pioneer-owned items is deliberately unnamed, because knowing how
many are really due would let the re-presented items — the ones that test whether a decision holds twice — be
counted out.

## T-5 (G-4) — the rule a new stop must meet

State 206. Written where contracts are drawn: expensive or impossible to reverse after this point, the agent
genuinely unable to make it, and servable in under a page with the choices named. Plus the negative — a flag
that only informs is not a flag — and the clause that matters most for the long run: *if the agent keeps
needing the pioneer for the same thing, that is the standard missing a rule, not a stop that belongs.*

## T-6 (G-5) — nothing else broke

- `walk-007` 172 states, `walk` 65 matching `walk.expected`, `walk-004` 51; all ten checks exit 0.
- **The red test.** The waiting list was changed to print the number of items a batch holds. State 205 failed,
  naming the line that carried the number. Restored: green again.
- The always-loaded layer did not grow — everything added here lives in the contract skill, a hook and a
  script, none of which carries an allowance.
- **No test of an earlier contract changed.** The first contract in a while where nothing earlier had to move.

## T-7 (all) — an independent agent

**Deferred, not claimed.** It asks whether an agent given only the kit's text draws a contract that leads with
the bearing and asks nothing at the gate but the three. That is a behaviour test of text written minutes ago,
and running it against the same session that wrote the text proves less than it appears to: the phrasing is
still in the writer's head. It is worth running in a session that has not seen this contract, which is the next
session.

## What this does not establish

- Whether the waiting list lowers the pioneer's load or simply adds a line they skim. Only use shows that, and
  the list has been read once, by its author.
- Whether three asks at the gate is the right number. It is what the practice has grown, not what anyone
  measured.
- Whether the bearing-first shape survives contact with a long contract. The two contracts drawn since the rule
  was written both did it, and both were drawn by the agent that wrote the rule.
